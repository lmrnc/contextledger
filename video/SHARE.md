# Application sharing description

ContextLedger is a local n8n portfolio prototype for governing the knowledge AI agents retrieve. This 90-second demo follows a conflicting policy and a department owner’s submission from review to approval. The same employee query then returns the approved version with its source provenance. Five workflows enforce taxonomy, ownership and access, with the same retrieval policy over HTTP and MCP. Northstar Labs and its source feeds are synthetic. The video includes AI-generated narration.
