# Knowledge contribution template

- Title
- Department and topic from the shared taxonomy
- Type from policy, procedure, decision, runbook or reference
- Designated owner and backup contact
- Audience and classification
- Canonical source link
- Policy or procedure with scope, exact thresholds and units, exceptions and effective date
- Verification date and next review date
- Change summary and links to affected old guidance

The adapter maps fields into ContextLedger. Preserve the source's actual modification timestamp. A source edit opens a review for a governed topic. An owner must verify the edit before it reaches approved context.
